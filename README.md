# Calcular-Media
# 📚 Projeto: Cálculo de Média Escolar

Este é um projeto simples desenvolvido em **C# com Windows Forms**, com o objetivo de **calcular a média de até 3 notas de um aluno** e informar se ele está **aprovado ou reprovado**, de acordo com o resultado.

Foi desenvolvido como parte de um trabalho escolar para treinar a lógica de programação e o uso da interface gráfica no Visual Studio.

## 🎯 Funcionalidades

- Inserção de até **três notas**.
- Cálculo da **média aritmética**.
- Exibição do resultado com:
  - Valor da média
  - Mensagem de aprovação ou reprovação
- Interface gráfica simples e intuitiva

## 💻 Tecnologias Utilizadas

- C# (.NET Framework)
- Windows Forms
- Visual Studio
